# 内存分配设计修复方案 - 代码实现

## 方案 A：统一占顶指针（推荐）

本方案展示如何将两套占顶指针统一为一个，彻底解决地址冲突问题。

### 3.3 修改 sys_user_allocate_mem

```c
uint64 sys_user_allocate_mem(int n) {
    if (n <= 0) {
        return (uint64)NULL;
    }
    n = ROUNDUP(n, 8);  // 8字节对齐

    // ✅ 统一的分配逻辑
    
    // 尝试在空闲链表中分配
    uint64 alloc_pa = current->alloc(n, &current->free_list, &current->alloc_list);
    
    if (alloc_pa != (uint64)NULL) {
        return pa_to_user_va((pagetable_t)current->pagetable, alloc_pa);
    }
    
    // 空闲链表中没有合适的块，分配新页
    void *pa = alloc_page();
    if (pa == NULL) {
        return (uint64)NULL;
    }
    
    uint64 alloc_va = current->heap_top;  // ✅ 使用统一的占顶指针
    user_vm_map((pagetable_t)current->pagetable, alloc_va, PGSIZE, (uint64)pa,
                prot_to_type(PROT_WRITE | PROT_READ, 1));
    
    current->heap_top += PGSIZE;  // ✅ 单一占顶指针安全增长
    
    // 将新页的剩余空间加入空闲链表
    pd *new_free_block = (pd *)pa;
    new_free_block->flag = 0;
    new_free_block->size = PGSIZE - sizeof(pd);
    new_free_block->next = NULL;
    insert_free_block(&current->free_list, new_free_block, pd_first_fit_cmp);

    // 再次尝试分配
    alloc_pa = current->alloc(n, &current->free_list, &current->alloc_list);
    if (alloc_pa != (uint64)NULL) {
        return pa_to_user_va((pagetable_t)current->pagetable, alloc_pa);
    }
    
    return (uint64)NULL;
}
```

### 3.5 修改 sys_user_exit 的清理逻辑

```c
ssize_t sys_user_exit(uint64 code) {
    sprint("User exit with code:%d.\n", code);
    
    // 处理进程队列
    process *tmp = wake_from_block_queue(&block_queue_head, current);
    free_process(current);

    // ✅ 统一的内存清理逻辑
    // 1. 释放所有已分配的块
    if (current->alloc_list != NULL) {
        pd *alloc_item = current->alloc_list;
        while (alloc_item) {
            uint64 alloc_addr = (uint64)(alloc_item) + sizeof(pd);
            current->free(alloc_addr, &current->free_list, &current->alloc_list);
            alloc_item = current->alloc_list;
        }
    }
    
    // 2. 对空闲链表进行排序和合并
    sort_free_list_ascend(&current->free_list, pd_first_fit_cmp);
    merge_free_blocks(&current->free_list, pd_first_fit_cmp);

    // 3. 遍历空闲链表，取消映射并释放物理页
    pd *free_item = current->free_list;
    while (free_item) {
        pd *next_item = free_item->next;
        
        uint64 page_va = (uint64)free_item & ~(PGSIZE - 1);  // 页对齐
        uint64 page_offset = (uint64)free_item - page_va;
        
        // ✅ 改进的 VA 转换逻辑：直接从 heap 范围查找
        for (uint64 va = USER_FREE_ADDRESS_START; va < current->heap_top; va += PGSIZE) {
            uint64 map_pa = lookup_pa((pagetable_t)current->pagetable, va);
            if (map_pa != 0) {
                uint64 block_pa = (uint64)free_item;
                if (block_pa >= map_pa && block_pa < map_pa + PGSIZE) {
                    // 找到了映射关系
                    user_vm_unmap((pagetable_t)current->pagetable, va, PGSIZE, 1);
                    break;
                }
            }
        }
        
        free_item = next_item;
    }
    
    // 处理调度
    if (tmp == NULL) {
        schedule();
        return 0;
    }
    current = tmp;
    current->status = READY;
    insert_to_ready_queue(current);
    schedule();
    return 0;
}
```

## 步骤 4：修改 vmm.c 中的 pa_to_user_va 函数

**当前实现的问题**：只扫描到 `user_heap_top`

```c
// ❌ 现有实现
uint64 pa_to_user_va(pagetable_t page_dir, uint64 pa) {
    uint64 map_pa;
    for (uint64 va = USER_FREE_ADDRESS_START; va < current->user_heap_top; va += PGSIZE) {
        map_pa = lookup_pa(page_dir, va);
        if (map_pa == 0) continue;
        if (pa >= map_pa && pa < map_pa + PGSIZE) {
            return va + (pa - map_pa);
        }
    }
    return (uint64)NULL;
}
```

**修改为**：

```c
// ✅ 改进的实现：使用统一的 heap_top
uint64 pa_to_user_va(pagetable_t page_dir, uint64 pa) {
    uint64 map_pa;
    
    // ✅ 扫描整个堆区间（使用了统一的 heap_top）
    for (uint64 va = USER_FREE_ADDRESS_START; va < current->heap_top; va += PGSIZE) {
        map_pa = lookup_pa(page_dir, va);
        if (map_pa == 0) continue;
        
        // ✅ 检查物理地址是否在这一页内
        if (pa >= map_pa && pa < map_pa + PGSIZE) {
            // 返回页内偏移的虚拟地址
            return va + (pa - map_pa);
        }
    }
    
    // 未找到对应映射
    return (uint64)NULL;
}
```

## 总结

通过统一占顶指针，我们解决了：

1. ✅ **虚拟地址空间冲突**：单一的 `heap_top` 确保顺序分配
2. ✅ **pa_to_user_va 的完整性**：扫描整个 heap 范围
3. ✅ **进程退出内存泄漏**：统一的清理逻辑
4. ✅ **fork 状态不一致**：子进程从新的堆开始
5. ✅ **跨页分配脆弱性**：简化的分配算法

**修改工作量**：约 200-300 行代码改动，80% 是删除不必要的复杂逻辑。
